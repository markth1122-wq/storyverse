# StoryVerse AI — รุ่นเตรียม Build APK ผ่าน Cloud

ชุดนี้เพิ่มไฟล์ GitHub Actions เพื่อให้ GitHub สร้าง APK ให้ โดยไม่ต้องติดตั้ง Flutter หรือ Android SDK ในมือถือ

## สิ่งที่มี
- แอปต้นแบบ Flutter: หน้าหลัก, เขียนนิยาย, สตอรี่บอร์ด, คลังงาน, ตั้งค่า
- บันทึก/โหลดนิยายในเครื่อง
- Workflow สำหรับสร้าง APK บน GitHub Actions

## วิธีทำผ่านมือถือ Android
1. สมัคร/เข้าสู่ระบบ GitHub ที่ https://github.com
2. สร้าง Repository ใหม่ ตั้งชื่อ `storyverse-ai` และเลือก Public (เพื่อใช้โควต้าฟรีของ GitHub Actions ได้สะดวก) ไม่ต้องเพิ่ม README, .gitignore หรือ License
3. แตกไฟล์ ZIP นี้ในมือถือด้วยแอปจัดการไฟล์
4. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจากข้างในไปยัง Repository โดยรักษาโครงสร้างโฟลเดอร์ เช่น `lib/main.dart` และ `.github/workflows/build-apk.yml`
   - หากหน้าเว็บมือถืออัปโหลดโฟลเดอร์ไม่ได้ ให้เปิด GitHub ในเบราว์เซอร์และใช้โหมดเว็บไซต์เดสก์ท็อป หรือใช้แอปจัดการไฟล์ร่วมกับ Git client บน Android
5. เมื่ออัปโหลดเข้า branch `main` แล้ว เปิดแท็บ Actions ใน Repository
6. เลือก `Build StoryVerse AI APK` แล้วกด Run workflow หากงานยังไม่เริ่มเอง
7. รอจนสถานะเป็นสีเขียว แล้วเปิดงานล่าสุด เลื่อนลงไปที่ Artifacts และดาวน์โหลด `StoryVerse-AI-APK`
8. แตก ZIP ที่ดาวน์โหลด แล้วแตะ `app-release.apk` เพื่อติดตั้ง

## หมายเหตุสำคัญ
- GitHub Actions เป็นบริการภายนอกและเงื่อนไข/โควต้าฟรีอาจเปลี่ยนได้
- Repository แบบ Public ทำให้ซอร์สโค้ดมองเห็นได้โดยคนอื่น อย่าใส่ข้อมูลส่วนตัวหรือ API keys
- หากต้องการเก็บซอร์สโค้ดเป็นส่วนตัว อาจมีข้อจำกัดโควต้าหรือเงื่อนไขตามบัญชี GitHub
- Android อาจถามให้อนุญาตติดตั้งแอปจากแหล่งที่มานี้ ให้ติดตั้งเฉพาะ APK ที่คุณสร้างเองจาก workflow นี้
- APK นี้ยังเป็นต้นแบบ ไม่มี AI จริง, สร้างภาพ/วิดีโอ, เสียงพูด หรือตัดต่อ MP4
- ข้อมูลนิยายใช้พื้นที่เก็บข้อมูลในแอป (shared_preferences) ควรสำรองข้อมูลก่อนถอนการติดตั้งแอป

## Build เอง (หากภายหลังมีคอมพิวเตอร์)
`flutter pub get`
`flutter build apk --release`
