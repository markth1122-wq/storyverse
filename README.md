# StoryVerse AI 1.0 — Android starter

ต้นแบบ Flutter ภาษาไทยสำหรับแอปสร้างนิยายและเตรียมงานภาพยนตร์ AI ใช้ส่วนตัว

## มีอะไรในรุ่นนี้
- หน้าหลักและเมนูนำทาง
- หน้าจอเขียนนิยาย
- บันทึก/โหลดชื่อเรื่องและเนื้อหาด้วย SharedPreferences ในเครื่อง
- หน้าตัวอย่างสตอรี่บอร์ด 8 ฉาก
- หน้าคลังภาพและตั้งค่า (โครงร่าง)

## ยังไม่มีในรุ่นนี้
- AI เขียนนิยายจริง
- สร้างภาพหรือวิดีโอจริง
- สร้างเสียงพูด
- ตัดต่อและส่งออก MP4
- APK ที่คอมไพล์แล้ว

## วิธีเปิดโปรเจกต์
ต้องติดตั้ง Flutter SDK และ Android SDK บนคอมพิวเตอร์ก่อน

```bash
flutter pub get
flutter run
```

## วิธีสร้าง APK
```bash
flutter build apk --release
```
ไฟล์จะอยู่ที่ `build/app/outputs/flutter-apk/app-release.apk`

## หมายเหตุด้านความปลอดภัย
อย่าใส่ API key ไว้ในแอป Android โดยตรง หากเพิ่มบริการ AI ในอนาคตควรใช้ backend/proxy ที่ปกป้องกุญแจ API
